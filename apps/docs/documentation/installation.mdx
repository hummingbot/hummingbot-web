The fastest way to run Hummingbot is the deploy script, which sets up the
client and supporting services via Docker.

## Prerequisites

- A machine running Linux (Ubuntu 20.04+) or macOS
- [Docker](https://docs.docker.com/get-docker/) installed and running

## Install

From an empty directory, run:

```bash
curl -fsSL https://hummingbot.org/install.sh | bash
```

The installer pulls the latest images and guides you through configuration.

<Note>
  To run an AI agent harness (Telegram + LLM control) on top of Hummingbot,
  install **Condor** instead — see the Condor tab's
  [installation guide](/installation).
</Note>
